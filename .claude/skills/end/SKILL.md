# End Session Skill (session-logger)

세션 종료 시 진행기록을 생성합니다.
`/start` 스킬과 대칭 구조입니다.

---

## 핵심 목적

**다음 세션을 시작할 때 중복/누락 없이 프로젝트를 정확히 인지하고 이어갈 수 있도록 기록하는 것.**

이 기록이 부정확하면:
- 매번 프로젝트 전체 코드를 다시 확인해야 함
- 이미 한 작업을 반복하게 됨
- 전체 흐름/코드 이해 부족으로 버그 발생

따라서 **정확성과 완전성이 최우선**입니다.

---

## 필수 규칙 (반드시 지킬 것)

### 1. 추가구현 문서 통합 (최중요!)

사용자는 2개의 Claude를 사용합니다:
- **Claude Code** (이 세션) — 플랜/설계/안내
- **웹 Claude** (별도) — 추가 학습 및 구현

**세션 종료 시 `진행기록/` 폴더의 추가구현 파일을 반드시 확인하고 통합해야 합니다!**

#### 통합 대상 파일 패턴
```
*_추가구현.md
*_추가구현1.md, *_추가구현2.md
*_추가구현통합.md
*_추가.md, *_구현.md
```

#### 확인 범위
- 이번 회차의 추가구현 파일
- 이전 회차 중 아직 메인 진행기록에 반영되지 않은 추가구현 파일

#### 통합 방법
```markdown
## 오늘 한 일

### Claude Code 세션
- [x] 이 세션에서 한 작업들

### 별도 학습/구현 (추가구현 참조)
- [x] 사용자가 별도로 한 작업들
```

**추가구현 원본 파일은 절대 삭제하지 않습니다** — 원본 보존.

### 2. 전체 진행 상황 요약 필수

> **최신 문서만 봐도 프로젝트 전체 진척도를 즉시 파악할 수 있어야 합니다.**

- "완료된 시스템" 섹션에 이전 회차 완료 내용도 **누적 기록**
- "현재 구현 상태"에 모든 클래스의 변수/함수 목록을 정확히 반영
- 이번 세션에서 변경/추가된 것은 `(NEW)` 또는 `(수정)` 표시

### 3. 자동 저장

세션 종료 시 반드시 `E:\UnrealProject\ChaosYut_New\진행기록\`에 .md 파일을 자동 생성합니다.

### 4. 다음에 이어갈 것은 구체적으로

- 막연한 "계속 진행" 금지
- 구체적인 작업 항목과 확인 포인트 명시
- 우선순위 표시

## 실행 단계

### 1단계: 추가구현 파일 확인
```
Glob: E:\UnrealProject\ChaosYut_New\진행기록\*추가*.md
Glob: E:\UnrealProject\ChaosYut_New\진행기록\*구현*.md
```
- 최신 회차의 추가구현 파일이 있으면 읽기
- 이전 회차 추가구현 중 미반영 내용 확인

### 2단계: 이전 진행기록 확인
- 가장 최근 메인 진행기록을 읽어서 "완료된 시스템" 누적 목록 확인
- 이번 세션에서 새로 완료된 항목 파악

### 3단계: 이번 세션 내용 정리
현재 대화에서 수행한 작업들을 정리:
- 완료한 작업 (체크리스트)
- 설계/계획한 내용
- 해결한 문제/버그
- 학습한 개념
- 결정된 사항
- 주요 논의 내용
- 중요한 대화 하이라이트

### 4단계: 진행기록 파일 생성
파일명: `YYMMDD_N회차_진행상황.md`

### 5단계: 생성 확인
파일이 정상 생성되었는지 확인 후 사용자에게 요약 보고
