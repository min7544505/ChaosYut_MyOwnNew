## 해결한 버그들

### 1. 컴파일 오류 4개
**원인:** Cast To BP_YutBoard 불필요 + Target 연결 누락
**해결:** Cast 삭제, GET(0) 직접 연결

### 2. Piece_C가 (0,0,0)으로 이동하는 문제
**원인:** BeginPlay에서 WaitingPosition 초기화 코드가 삭제되어 있었음
**해결:** `GetActorLocation → SET WaitingPosition` 복구

### 3. 잡기 방향 반대 (핵심 버그!)
**증상:** 나중에 도착한 말이 리셋됨 (반대로 동작)
**원인:** ResetToWaiting의 Target이 Self로 연결되어 있었음
**해결:** Target을 Array Element로 변경 → 먼저 있던 말(상대)이 리셋됨

## 수정된 MoveTo 잡기 로직

```
[For Each Loop: TargetRoad.OccupyingPieces]
    ↓
[Array Element == Self?]
├── True → 스킵 (자기 자신)
└── False
    ↓
    [TeamIndex 비교]
    ├── 같은 팀 → StackWith(Array Element)
    └── 다른 팀 → Array Element.ResetToWaiting()  ← Target = Array Element!
```
