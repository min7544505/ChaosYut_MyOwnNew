### 2. DataTable 수정 - START Road 분리
**문제**: C1이 시작점과 골인점을 동시에 담당하여 로직 충돌

**해결**: START Road 신설로 역할 분리

| RoadID | NextRoads | PrevRoads | 역할 |
|--------|-----------|-----------|------|
| **START** | O_L | (비어있음) | 시작 전용 |
| **C1** | (비어있음) | O_P \| D_H | 골인 지점 |

- 총 Road 수: 29개 → **30개**
- Row 0번에 START 배치
- BP_YutBoard의 StartRoad 참조 변경: C1 → START

### 3. BP_RoadBase 함수 구현
#### GetNextRoad (완료)
| 항목 | 값 |
|------|-----|
| **Input** | bPreferDiagonal (Boolean) |
| **Output** | NextRoad (BP_RoadBase) |
| **역할** | 다음 이동할 Road 반환 |

**로직**:
```
NextRoads.Length 체크
├── 0개 → Return None (골인 지점)
├── 1개 → Return NextRoads[0] (선택지 없음)
└── 2개 → bPreferDiagonal에 따라 선택 (분기점)
```

#### GetPrevRoad (완료)
| 항목 | 값 |
|------|-----|
| **Input** | bPreferDiagonal (Boolean) |
| **Output** | PrevRoad (BP_RoadBase) |
| **역할** | 백도 시 이전 Road 반환 |

**GetNextRoad와 동일 구조**, NextRoads → PrevRoads로 변경

#### OnPieceEnter (완료)
| 항목 | 값 |
|------|-----|
| **Input** | Piece (BP_YutPiece) |
| **역할** | 말 도착 시 처리 |

**로직**:
```
Piece.CurrentRoad = Self (양방향 참조)
OccupyingPieces.Add(Piece) (Road가 말 기억)
```

#### OnPieceExit (완료)
| 항목 | 값 |
|------|-----|
| **Input** | Piece (BP_YutPiece) |
| **역할** | 말 출발 시 정리 |

**로직**:
```
OccupyingPieces.Remove Item(Piece) (목록에서 제거)
Piece.CurrentRoad = None (참조 해제)
```

## 학습한 개념

### 1. bPreferDiagonal의 역할
- "어디서 왔는지"가 아닌 **"유저가 어디로 가고 싶은지"** 전달
- 분기점(앞으로 갈 때), 합류점(백도 시) 모두 **유저 선택** 기반

### 2. 양방향 참조 구조
```
┌─────────────────┐         ┌─────────────────┐
│   BP_YutPiece   │         │   BP_RoadBase   │
├─────────────────┤         ├─────────────────┤
│ CurrentRoad ────┼────────→│                 │
│                 │←────────┼── OccupyingPieces│
└─────────────────┘         └─────────────────┘
```

| 방향 | 용도 |
|------|------|
| 말 → Road | 말 이동 시 현재 위치 확인 |
| Road → 말 | 잡기/업기 판정 시 확인 |

### 3. Array 노드 구분
| 노드 | 용도 |
|------|------|
| **Add** | 배열 끝에 요소 추가 |
| **Remove Item** | 특정 객체를 찾아서 제거 |
| **Remove Index** | 특정 위치(인덱스)의 요소 제거 |

## 핵심 설계 결정 사항

### 1. START Road 분리 (4회차)
```
변경 전: C1이 시작점 + 골인점
변경 후: START(시작) + C1(골인) 분리
```

### 2. 유저 선택 기반 경로 결정
```
분기점 (앞으로): NextRoads 2개 → 유저 선택
합류점 (백도): PrevRoads 2개 → 유저 선택
```

### 3. 양방향 참조 구조
```
Piece.CurrentRoad ←→ Road.OccupyingPieces
```
