## 구현된 시스템 상세

### ResetToWaiting 함수
- CurrentRoad 유효 시 OnPieceExit 호출
- CurrentRoad, CarrierPiece를 None으로 초기화
- StackedPieces를 For Each Loop로 순회하며 재귀 호출 (연쇄 리셋)
- StackedPieces Clear 후 WaitingPosition으로 SetActorLocation

### StackWith 함수
- OtherPiece의 CarrierPiece 유무로 바닥 말(BottomPiece) 결정
- Self의 StackedPieces를 바닥 말에게 전달 (CarrierPiece 변경 포함)
- Self를 바닥 말의 StackedPieces에 추가
- Self.CurrentRoad = None (업힌 말은 Road에 등록하지 않음)

### MoveTo 잡기/업기 로직
- OnPieceEnter 이후 OccupyingPieces를 For Each Loop로 순회
- Self 체크 → 자기 자신 스킵
- 같은 팀 → StackWith 호출 (업기)
- 다른 팀 → CarrierPiece 유무 확인 후 바닥 말의 ResetToWaiting 호출 (잡기)

## 학습한 개념

### 바닥 말 vs 업힌 말 구조
| 역할 | CurrentRoad | CarrierPiece | StackedPieces |
|------|-------------|--------------|---------------|
| 바닥 말 (운전기사) | 유지 | None | 업힌 말들 |
| 업힌 말 (승객) | None | 바닥 말 참조 | 비어있음 |

### 설계 결정
- 바닥 말만 OccupyingPieces에 등록 (중복 방지)
- 먼저 있던 말이 바닥 말이 됨
- 업힌 말들은 바닥 말 변경 시 전부 이전 (운전기사 교체)

---

## 결정된 사항

- 잡기: 바닥 말의 ResetToWaiting 호출 → 재귀로 전원 리셋
- 업기: 바닥 말 찾아서 StackWith → Self.CurrentRoad = None
- 업힌 말은 Road에 등록하지 않음 (바닥 말만 등록)

## 메모

- Self = 새로 도착한 말, OtherPiece = 이미 있던 말 (헷갈리지 말 것)
- SET 노드: Target = "누구의" 변수, 값 핀 = "어떤 값으로"
- 업힌 말의 위치 확인: `업힌말.CarrierPiece.CurrentRoad`
- For Loop 안 Delay는 작동 안 함 (재귀 호출 패턴 필요 - 미해결)
