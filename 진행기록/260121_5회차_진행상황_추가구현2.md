**구현된 로직:**
```
[TargetRoad] → [IsValid?]
```

**핵심 포인트:**
- OnPieceEnter/OnPieceExit **호출 없음**
- CurrentRoad **변경 없음** (경유만 하므로)
- 잡기/업기 **발동 안 함**

### 2. CalculatePath 함수 구현 (BP_YutBoard)

**Source:** 5회차-1 진행상황 - CalculatePath 함수 설계

| 항목 | 값 |
|------|-----|
| **Input** | StartRoad (BP_RoadBase), Steps (Integer), bPreferDiagonal (Boolean) |
| **Output** | Path (Array of BP_RoadBase) |
| **역할** | 이동 경로 배열 생성 |

**구현된 로직:**
```
CurrentRoad = StartRoad
PathArray = []

For Loop (0 ~ Steps-1):
├── NextRoad = CurrentRoad.GetNextRoad(bPreferDiagonal)
├── NextRoad 유효?
│   ├── Yes → PathArray.Add(NextRoad), CurrentRoad = NextRoad
│   └── No → 아무것도 안 함 (골인 도달)

Return PathArray
```

**로컬 변수:**
| 이름 | 타입 | 용도 |
|------|------|------|
| CurrentRoad | BP_RoadBase | 현재 탐색 중인 Road |
| NextRoad | BP_RoadBase | GetNextRoad 결과 저장 |
| PathArray | Array of BP_RoadBase | 경로 배열 (Add용) |

**예시:**
| Input | 예상 Output |
|-------|-------------|
| (START, 3, false) | [O_L, O_J, O_H] |
| (O_P, 2, false) | [C1] (1칸만, C1이 골인이라 NextRoad 없음) |

### 3. MoveAlongPath Custom Event 구현 (BP_YutPiece)

**Source:** 5회차-1 진행상황 - MoveAlongPath 함수 설계

| 항목 | 값 |
|------|-----|
| **타입** | Custom Event (함수 아님) |
| **Input** | Path (Array of BP_RoadBase) |
| **Output** | None |
| **역할** | 경로 배열을 따라 순차적으로 이동 |

**함수 → Custom Event로 변경한 이유:**
- **함수 내에서 Delay 노드 사용 불가** (Latent 노드)
- Custom Event는 비동기 실행 가능

**구현된 로직:**
```
[Custom Event: MoveAlongPath]
        │
      Path → [Length > 0?] → Branch
                               │
                    ┌──────────┴──────────┐
                  False                 True
                    │                     │
                    ▼                     ▼
                [Return]           [Length - 1]
                                        │
                           ┌────────────┼────────────┐
                           │            │            │
                           ▼            ▼            ▼
              [For Loop with Break]  [Equal ==]  [GET Path[Index]]
               ├── First: 0             ↑              │
               ├── Last: Length-1       │         Return Value
               │                        │              │
               ├── Loop Body            │              ▼
               │       │                │    ┌────────┴────────┐
               │       ▼                │    │                 │
               │   [Index == Last?] ────┘    ▼                 ▼
               │       │                  [MoveTo]      [MoveThrough]
               │ ┌─────┴─────┐           (마지막)         (경유)
               │ True      False              │              │
               │   │          │               │              ▼
               │   ▼          ▼               │          [Delay 0.2]
               │ [MoveTo] [MoveThrough]       │
               │              │               │
               │              ▼               │
               │          [Delay 0.2]         │
               │                              │
               └── Completed ─────────────────┘
```

**핵심 포인트:**
- **경유 칸 (Index ≠ LastIndex)**: MoveThrough + Delay 0.2초
- **최종 칸 (Index == LastIndex)**: MoveTo (잡기/업기/골인 체크 발동)
- **로컬 변수 없이 직접 계산**: Length - 1을 For Loop와 Equal에 직접 연결

## 학습한 개념

### 1. 함수 vs Custom Event

**Source:** Debugger Agent - Latent 노드 문제

| 항목 | 함수 (Function) | Custom Event |
|------|-----------------|--------------|
| **실행 방식** | 동기 (Synchronous) | 비동기 (Asynchronous) |
| **Latent 노드** | ❌ 사용 불가 | ✅ 사용 가능 |
| **Delay** | ❌ 불가 | ✅ 가능 |
| **Return Value** | ✅ 가능 | ❌ 불가 |

### 2. 로컬 변수의 스코프 제한

**문제:** 함수에서 만든 로컬 변수는 Event Graph에서 사용 불가

**해결:** 
- 로컬 변수 대신 직접 계산 (Length - 1)
- 또는 클래스 변수로 승격 (비권장)

### 3. Cast 노드 필요성

**Source:** 2회차 진행상황 - Object Reference vs Class Reference

**문제:** Get All Actors of Class는 Actor 타입 반환 → BP_YutBoard 함수 접근 불가

**해결:** Cast to BP_YutBoard로 타입 변환 후 함수 호출

## 4개 이동 함수 관계도

**Source:** 5회차-1 진행상황 - 함수 분리 구조

```
[윷 던지기] → Steps (예: 3)
     │
     ▼
┌──────────────────────────────────────┐
│ CalculatePath (BP_YutBoard)          │
│                                      │
│ "어디로 갈지 계산만 함"              │
│ Output: Path = [O_L, O_J, O_H]       │
└──────────────────────────────────────┘
     │
     ▼
┌──────────────────────────────────────┐
│ MoveAlongPath (BP_YutPiece)          │
│                                      │
│ "경로를 따라 실제로 이동"            │
│ 경유 칸: MoveThrough + Delay         │
│ 최종 칸: MoveTo                      │
└──────────────────────────────────────┘
     │
     ├── MoveThrough (경유) ──→ 시각적 이동만
     │
     └── MoveTo (최종) ──→ OnPieceEnter + 잡기/업기/골인
```

### MoveThrough vs MoveTo 비교

| 항목 | MoveThrough | MoveTo |
|------|-------------|--------|
| **용도** | 경유 칸 | 최종 도착 칸 |
| **SetActorLocation** | ✅ | ✅ |
| **OnPieceExit** | ❌ | ✅ |
| **OnPieceEnter** | ❌ | ✅ |
| **CurrentRoad 변경** | ❌ | ✅ |
| **잡기/업기** | ❌ | ✅ |
| **골인 체크** | ❌ | ✅ |

## 메모

- **Delay는 함수에서 사용 불가** → Custom Event로 변환 필요
- **로컬 변수는 해당 함수 내에서만 유효** → Event Graph에서 접근 불가
- **Cast 실패 시 None 반환** → IsValid 체크 필수
- **테스트 시 Board 초기화 대기 필요** → Delay 1초 추가
