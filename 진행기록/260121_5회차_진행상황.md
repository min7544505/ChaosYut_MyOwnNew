## 해결한 버그들

### 1. CalculatePath → MoveAlongPath 연결 문제
**문제:** 둘 다 output 핀이라서 연결 불가

**원인:** Custom Event는 "정의"와 "호출"이 별도 노드
- Custom Event 노드: 정의 (Path가 출력 핀)
- Call 노드: 호출 (Path가 입력 핀)

**해결:** 우클릭 → "MoveAlongPath" 검색 → Call 노드 사용

### 2. CalculatePath가 1칸만 계산하는 문제
**증상:** Steps=3인데 Path.Length=1

**원인:** For Loop 또는 CurrentRoad 업데이트 문제

**해결:** CalculatePath 내부 로직 수정

### 3. C2(분기점)에서 이동 멈춤 문제
**증상:** 6칸 이동 시 C2에서 멈춤, GetNextRoad 내부 Print 출력 안 됨

**디버깅 과정:**
1. DebugPrintConnectionRoads로 C2의 NextRoads 확인 → O_D, D_B 2개 정상
2. GetNextRoad 내부 NextRoads.Length 출력 → C2에서 호출 시 출력 안 됨
3. BP_BranchRoad 상속 구조 확인 → 정상 (BP_RoadBase 상속)
4. BP_BranchRoad에 중복 변수 확인 → 없음

**원인:** BP_BranchRoad에 빈 GetNextRoad 함수가 Override 되어 있었음

**해결:** BP_BranchRoad의 GetNextRoad 함수 삭제

## 학습한 개념

### 1. Custom Event vs 함수
| 항목 | 함수 | Custom Event |
|------|------|--------------|
| 별도 그래프 | O (캡슐화) | X (Event Graph에 펼쳐짐) |
| Delay 사용 | X | O |
| Return Value | O | X |
| 호출 방법 | 직접 호출 | Call 노드 필요 |

### 2. Custom Event 정리 팁
- 관련 노드 선택 → 우클릭 → Create Comment (코멘트 박스로 묶기)

### 3. Print String으로 여러 값 출력
- Append 노드 사용: A + B 문자열 합치기
- 또는 Print String 여러 개 사용
