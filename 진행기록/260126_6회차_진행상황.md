## 해결한 문제

### MoveAlongPath Delay가 작동하지 않는 문제
**증상:** 10스텝을 입력하면 순차 이동 없이 바로 10번째 칸으로 이동

**원인:** For Loop는 Delay를 기다리지 않음
- For Loop는 동기적(Synchronous)으로 실행
- Delay 노드를 만나도 "Delay 시작만 하고" 바로 다음 반복으로 진행
- 결과: 모든 이동이 거의 동시에 실행 → 마지막 위치만 보임

**해결책:** 재귀 호출 패턴으로 변경
- For Loop 대신 Index를 파라미터로 받아서 Delay 후 자기 자신을 다시 호출
- 또는 Timeline 활용

**결정:** 애니메이션 이동 구현할 때 함께 수정하기로 함 (현재는 보류)

## 잡기/업기 설계 (구현 예정)

### 규칙 확인
| 상황 | 동작 | 추가 효과 |
|------|------|-----------|
| **상대팀 말** 위에 도착 | 잡기 - 상대 말 원위치 | 추가 던지기 (윷/모 제외) |
| **우리팀 말** 위에 도착 | 업기 - 그룹으로 이동 | 없음 |
| **업힌 말**이 잡히면 | 모든 말 함께 잡힘 | - |

- 업기는 필수 (선택권 없음)
- 대기 위치는 스폰 시 초기 위치를 저장

### BP_YutPiece 추가할 변수
| 변수명 | 타입 | 용도 |
|--------|------|------|
| StackedPieces | Array of BP_YutPiece | 내가 업고 있는 말들 |
| CarrierPiece | BP_YutPiece | 나를 업고 있는 말 |
| WaitingPosition | Vector | 대기 위치 (잡히면 복귀) |

### BP_YutPiece 추가할 함수
| 함수명 | 역할 |
|--------|------|
| ResetToWaiting | 잡혔을 때 대기 위치로 복귀, 업힌 말들도 함께 처리 |
| StackWith(OtherPiece) | 업기 처리 |

### OnPieceEnter 수정 계획
```
[OccupyingPieces.Length > 0?]
├── False → 그냥 진입
└── True
    → [같은 팀?]
       ├── True → 업기 (StackWith)
       └── False → 잡기 (ResetToWaiting)
```

### MoveTo 수정 계획
- 이동 시 StackedPieces도 함께 이동
