## 완료된 작업

### 1. BP_RoadBase - GetNextRoad 함수 수정

**Source:** 4회차 진행상황 - GetNextRoad 함수

**문제점:** 기존 로직이 For Each Loop + IsDiagonal 체크로 복잡하고 bPreferDiagonal 파라미터 미사용

**수정 후 로직:**
```
NextRoads.Length 체크 (Switch on Int)
├── 0개 → Return None (골인 지점)
├── 1개 → Return NextRoads[0] (선택지 없음)
└── 2개 → bPreferDiagonal에 따라 선택
              ├── True  → NextRoads[1] (대각선)
              └── False → NextRoads[0] (외곽)
```

**DataTable 저장 규칙 확인:**

**Source:** DataTable (DT_BoardLayout)

| RoadID | NextRoads | 인덱스 0 | 인덱스 1 |
|--------|-----------|----------|----------|
| C2 | O_D \| D_B | O_D (외곽) | D_B (대각선) |
| C3 | O_E \| D_A | O_E (외곽) | D_A (대각선) |

**핵심:** `bPreferDiagonal = True → [1]`, `False → [0]`

### 4. BP_YutPiece - MoveTo 함수 구현

**Source:** 4회차 진행상황 - BP_YutPiece 구조

| 항목 | 값 |
|------|-----|
| **Input** | TargetRoad (BP_RoadBase) |
| **Output** | None |
| **역할** | 말을 TargetRoad로 이동 |

**구현된 로직:**
```
┌─────────────────────────────────────────────────────────────────┐
│  [TargetRoad IsValid] ─── Is Not Valid ──→ [Return]             │
│         │                                                       │
│      Is Valid                                                   │
│         │                                                       │
│         ▼                                                       │
│  [CurrentRoad IsValid] ─── Is Not Valid ──┐                     │
│         │                                 │                     │
│      Is Valid                             │                     │
│         │                                 │                     │
│         ▼                                 │                     │
│  [Branch]                                 │                     │
│      │                                    │                     │
│  ┌───┴───┐                                │                     │
│ True   False                              │                     │
│  │       │                                │                     │
│  ▼       └────────────────┬───────────────┘                     │
│ [OnPieceExit(Self)]       │                                     │
│  │                        │                                     │
│  └────────────┬───────────┘                                     │
│               ▼                                                 │
│  [SetActorLocation(TargetRoad 위치)]                            │
│               │                                                 │
│               ▼                                                 │
│  [TargetRoad.OnPieceEnter(Self)]                                │
│               │                                                 │
│               ▼                                                 │
│  [NextRoads.Length == 0?] ─── Branch                            │
│               │                    │                            │
│           ┌───┴───┐                │                            │
│         True    False              │                            │
│           │       │                │                            │
│           ▼       ▼                │                            │
│  [Set IsFinished=True]  [Return]   │                            │
│           │                        │                            │
│           ▼                        │                            │
│      [Return]                      │                            │
└─────────────────────────────────────────────────────────────────┘
```

## 학습한 개념

### 1. CurrentRoad 유효성 검사 이유

**Source:** 4회차 진행상황 - BP_YutPiece 변수

| 상황 | CurrentRoad | 설명 |
|------|-------------|------|
| **대기 중인 말** | None (Invalid) | 아직 판에 올라가지 않음 |
| **판 위의 말** | 유효함 (Valid) | 정상적으로 이동 중 |

**처리:**
- Invalid → OnPieceExit 건너뛰고 바로 SetActorLocation
- Valid → OnPieceExit 실행 후 SetActorLocation

### 2. Branch의 False 핀 연결 필요성

**문제:** Branch의 True만 연결하면 False 케이스가 처리 안 됨

**해결:** False 핀도 SetActorLocation으로 연결 (대기 말도 이동해야 하므로)

### 3. SetActorLocation 옵션

| 옵션 | 기본값 | 윷놀이에서 |
|------|--------|-----------|
| **Sweep** | False | 불필요 (순간이동) |
| **Teleport** | False | 불필요 (물리 없음) |

### 4. START Road 규칙 정정

**Source:** DataTable - START Road

**잘못된 이해:**
```
대기 말 → MoveTo(START) → 다음 턴에 이동
```

**올바른 이해:**
```
대기 말 선택 → "START에서 시작"으로 판정 (가상)
→ 윷 결과만큼 이동 계산 → MoveTo(최종 목적지)
```

**핵심:** START는 실제로 머무는 곳이 아닌 **이동 계산 시작점**

## 메모

- **MoveTo의 CurrentRoad 유효성 검사**: 대기 말이 처음 판에 올라갈 때 필요
- **Branch False 핀**: 반드시 연결해야 함 (대기 말도 이동 필요)
- **경유 vs 최종 도착**: 잡기/업기는 최종 도착 칸에서만 발동
- **한 칸씩 이동 애니메이션**: MoveThrough + Delay 조합으로 구현 예정
