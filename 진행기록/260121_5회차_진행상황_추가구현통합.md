## 완료된 작업

### 1. BP_RoadBase - GetNextRoad 함수 수정
**Source:** 4회차 진행상황 - GetNextRoad 함수

**문제점:** 기존 로직이 For Each Loop + IsDiagonal 체크로 복잡하고 bPreferDiagonal 파라미터 미사용

**수정 후 로직:**
```
NextRoads.Length 체크 (Switch on Int)
├── 0개 → Return None (골인 지점)
├── 1개 → Return NextRoads[0] (선택지 없음)
└── 2개 → bPreferDiagonal에 따라 선택
    ├── True → NextRoads[1] (대각선)
    └── False → NextRoads[0] (외곽)
```

**DataTable 저장 규칙 확인:**

| RoadID | NextRoads | 인덱스 0 | 인덱스 1 |
|--------|-----------|----------|----------|
| C2 | O_D \| D_B | O_D (외곽) | D_B (대각선) |
| C3 | O_E \| D_A | O_E (외곽) | D_A (대각선) |

**핵심:** `bPreferDiagonal = True → [1]`, `False → [0]`

### 4. BP_YutPiece - MoveTo 함수 구현

| 항목 | 값 |
|------|-----|
| **Input** | TargetRoad (BP_RoadBase) |
| **Output** | None |
| **역할** | 말을 TargetRoad로 이동 + 게임 로직 처리 |

**구현된 로직:**
```
[TargetRoad IsValid?]
├── Not Valid → Return
└── Valid
    ↓
    [CurrentRoad IsValid?]
    ├── Valid → OnPieceExit(Self) → SetActorLocation
    └── Not Valid → SetActorLocation (대기 말)
    ↓
    [SetActorLocation(TargetRoad 위치)]
    ↓
    [TargetRoad.OnPieceEnter(Self)]
    ↓
    [TargetRoad.NextRoads.Length == 0?]
    ├── True → Set IsFinished = True (골인!)
    └── False → Return
```

### 5. BP_YutPiece - MoveThrough 함수 구현

| 항목 | 값 |
|------|-----|
| **Input** | TargetRoad (BP_RoadBase) |
| **Output** | None |
| **역할** | 경유 칸 이동 (시각적 이동만, 게임 로직 없음) |

**구현된 로직:**
```
[TargetRoad IsValid?]
├── Not Valid → Return
└── Valid → SetActorLocation(TargetRoad 위치) → Return
```

**MoveThrough vs MoveTo 비교:**

| 항목 | MoveThrough | MoveTo |
|------|-------------|--------|
| **용도** | 경유 칸 | 최종 도착 칸 |
| **SetActorLocation** | ✅ | ✅ |
| **OnPieceExit** | ❌ | ✅ |
| **OnPieceEnter** | ❌ | ✅ |
| **CurrentRoad 변경** | ❌ | ✅ |
| **잡기/업기** | ❌ | ✅ |
| **골인 체크** | ❌ | ✅ |

### 6. BP_YutBoard - CalculatePath 함수 구현

| 항목 | 값 |
|------|-----|
| **Input** | StartRoad (BP_RoadBase), Steps (Integer), bPreferDiagonal (Boolean) |
| **Output** | Path (Array of BP_RoadBase) |
| **역할** | 이동 경로 배열 생성 |

**구현된 로직:**
```
CurrentRoad = StartRoad
PathArray = []
For Loop (0 ~ Steps-1):
├── NextRoad = CurrentRoad.GetNextRoad(bPreferDiagonal)
├── NextRoad 유효?
│   ├── Yes → PathArray.Add(NextRoad), CurrentRoad = NextRoad
│   └── No → 아무것도 안 함 (골인 도달)
Return PathArray  ← Completed 핀에 연결!
```

**로컬 변수:**

| 이름 | 타입 | 용도 |
|------|------|------|
| CurrentRoad | BP_RoadBase | 현재 탐색 중인 Road |
| NextRoad | BP_RoadBase | GetNextRoad 결과 저장 |
| PathArray | Array of BP_RoadBase | 경로 배열 |

**예시:**

| Input | Output |
|-------|--------|
| (START, 3, false) | [O_L, O_J, O_H] |
| (START, 5, false) | [O_L, O_J, O_H, O_F, C2] |
| (O_P, 2, false) | [C1] (골인이라 1칸만) |

### 7. BP_YutPiece - MoveAlongPath Custom Event 구현

| 항목 | 값 |
|------|-----|
| **타입** | Custom Event (함수 아님 - Delay 사용 위해) |
| **Input** | Path (Array of BP_RoadBase) |
| **Output** | None |
| **역할** | 경로 배열을 따라 순차적으로 이동 |

**구현된 로직:**
```
[Custom Event: MoveAlongPath]
    ↓
[Path.Length > 0?]
├── False → Return
└── True
    ↓
    [For Loop] (0 ~ Length-1)
        ↓
        [Index == Length-1?] (마지막 칸인지)
        ├── True → MoveTo (최종 도착)
        └── False → MoveThrough (경유)
        ↓
        [Delay 0.2초]
    ↓
    Completed
```

## 디버깅 및 해결한 버그

### 버그 1: CalculatePath가 1칸만 이동
**증상:** Steps = 3 입력했는데 1칸만 이동
**원인:** Return 노드가 For Loop Body 안에 연결됨
**해결:** Return 노드를 For Loop의 **Completed** 핀에 연결

```
❌ 잘못된 연결:
Loop Body → GetNextRoad → Add → SET CurrentRoad → Return (1회 후 종료)

✅ 올바른 연결:
Loop Body → GetNextRoad → Add → SET CurrentRoad → (끊김, 자동 다음 반복)
Completed → Return PathArray
```

---

### 버그 2: C2(분기점)에서 다음 칸으로 안 넘어감
**증상:** Loop 5까지 정상, Loop 6에서 C2가 또 출력됨
**원인:** SET CurrentRoad = NextRoad가 실행 안 됨
**해결:** IsValid → True → Add → SET CurrentRoad 실행 핀 연결 확인

## 학습한 개념

### 1. 함수 vs Custom Event

| 항목 | 함수 (Function) | Custom Event |
|------|-----------------|--------------|
| **실행 방식** | 동기 (Synchronous) | 비동기 (Asynchronous) |
| **Latent 노드** | ❌ 사용 불가 | ✅ 사용 가능 |
| **Delay** | ❌ 불가 | ✅ 가능 |
| **Return Value** | ✅ 가능 | ❌ 불가 |

### 2. For Loop 실행 흐름

| Loop Body 끝에 | 동작 |
|----------------|------|
| **아무것도 연결 X** | 자동으로 다음 반복 실행 ✅ |
| **Return 연결** | 함수 즉시 종료 ❌ |
| **Completed 연결** | Loop 중간에 탈출 (잘못됨) |

### 3. Print String 디버깅

**Format Text 노드 사용법:**
```
Format: "Loop {Index}: Current={Cur}"
● Index ← For Loop의 Index
● Cur ← CurrentRoad.RoadID
```

**색상으로 구분:**

| 색상 | 용도 |
|------|------|
| 초록색 | 성공/시작 |
| 노란색 | 일반 정보 |
| 빨간색 | 에러/문제 |

### 4. 로컬 변수의 스코프 제한

**문제:** 함수에서 만든 로컬 변수는 Event Graph에서 사용 불가
**해결:** 로컬 변수 대신 직접 계산 (예: Length - 1)
